# CLAUDE.md — Cosmic Forge

Follow `AGENTS.md`. The skills in `skills/` are Claude Code skills (`SKILL.md` with frontmatter):
install them with `scripts/install.sh` / `scripts/install.ps1`, or as a plugin:
`/plugin marketplace add forpc1428-eng/cosmic-forge` then `/plugin install cosmic-forge@cosmic-forge`.

When a request involves a 3D / WebGL / Three.js / cinematic / scroll-animated site, invoke the
`cosmic-forge` skill first; it routes to the other seven skills. Default build = `templates/event-horizon`.
